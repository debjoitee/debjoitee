## Featured projects

### Bangaon Durga Puja Map Guide 2026

**Problem:** During Durga Puja, visitors in Bangaon need a quick way to find nearby pandals and get directions.

A mobile-first, bilingual (English/Bengali) React site built with Vite.

- Search across a 227-record pandal dataset by name, locality or jurisdiction
- Interactive OpenStreetMap map with list/map toggle and marker selection
- Optional live location, requested only when the visitor taps the button, used to sort pandals nearest-first
- Google Maps directions links (no API key needed) and share/copy support

**Engineering detail:** Location is processed entirely in the browser and never sent to a backend. The UI also states clearly that the coordinates are unverified and that this is an independent community guide, not an official site.

**Stack:** React · Vite · OpenStreetMap · Cloudflare Pages

[Source code](https://github.com/debjoitee/Durga_Pujo_Map_Guide_for_BANGAON_2026) &nbsp;·&nbsp; [Live site](https://durga-pujo-map-guide-for-bangaon-2026.pages.dev/)

### Annapurna Enterprise (Builder Store)

**Problem:** A construction-materials business needs an online catalogue where customers can browse products and place orders easily.

A product catalogue site with an admin side for managing it.

- Public storefront that loads the product list dynamically
- Customers order through a WhatsApp link
- Separate login, admin and dashboard pages in the codebase
- Firebase and a small `api` folder in the repository

**Stack:** HTML · CSS · JavaScript · Node.js · Firebase · Vercel

[Source code](https://github.com/debjoitee/builder-store-) &nbsp;·&nbsp; [Live site](https://builder-store-jade.vercel.app/)

### Zerodha-inspired trading platform (educational clone)

An independent learning project inspired by a stock-brokerage interface. It is **not** an official Zerodha product and not a real brokerage.

- Landing site and a separate dashboard app
- Signup and login flow with hashed passwords and token-based authentication
- Express backend with MongoDB storing holdings, positions, orders and users
- Frontend, dashboard and backend deployed separately

**Stack:** React · Node.js · Express · MongoDB · Netlify

[Source code](https://github.com/debjoitee/zerodha-clone) &nbsp;·&nbsp; [Landing site](https://verdant-truffle-145170.netlify.app/) &nbsp;·&nbsp; [Dashboard](https://zerodha-dashboard-app.netlify.app/)
