## 🚀 Featured Projects

### 🗺️ Bangaon Durga Puja Map Guide — 2026

A mobile-first, bilingual React guide to help people find Durga Puja pandals around Bangaon, West Bengal.

- 🔎 Search pandals by name or locality.
- 🗺️ Explore locations on an interactive map and open directions in Google Maps.
- 📍 Optional browser location, nearest-first sorting, and sharing features.
- 🌐 English/Bengali interface with mobile-friendly controls.

<a href="https://github.com/debjoitee/Durga_Pujo_Map_Guide_for_BANGAON_2026"><img src="https://img.shields.io/badge/Explore_Repository-181717?style=for-the-badge&logo=github&logoColor=white" alt="Explore Bangaon Durga Puja Map Guide repository" /></a>
